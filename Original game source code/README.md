## Gameplay

SpacePilot is a vertically scrolling bullet-hell space shooter rendered entirely in ASCII/terminal graphics.

- Fight through waves of enemies with distinct behaviours (hunters, rapid gunners, bombers, reflectors etc.)
- Battle challenging bosses with creative and unique mechanics, and difficult attack patterns
- Dodge dense enemy projectile patterns.
- Switch between multiple weapons from your inventory mid-fight.
- Choose from multiple playable ships (characters), each with different stats and weapon
- Play through Story Mode (scripted levels, dialogue, and bosses) or Endless Mode (procedurally scaling waves).
- Contains a high quality 8-bit soundtrack(entirely public domain music sourced from https://opengameart.org/)

## Controls

| Action | Key |
|---|---|
| Move | Arrow Keys / WASD |
| Fire | Space |
| Switch Weapon | Number keys (1–5) |
| Toggle Speed (fast/slow movement) | Q(while un-paused) |
| Mute Audio | M |
| Pause / Menu | P |
|Quit to Title-screen| Q(while paused)|
## Technical Information
It is coded entirely in C and is built entirely from scratch using a custom game engine.
For rendering, it uses the PDCurses Library. For sound effects, it uses Miniaudio.h.
